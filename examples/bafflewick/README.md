# Bafflewick acceptance example

Bafflewick is fictional.

The fixture starts at **Friday 16 October 2026 at 17:00 in Sydney** and adds **three business days** using the default Saturday/Sunday weekend. The expected deadline is **Wednesday 21 October 2026 at 17:00 +11:00**.

```bash
go build -o ./bin/obligation-clock ./cmd/obligation-clock
./bin/obligation-clock -input examples/bafflewick/request.json
```

This is arithmetic evidence only. It does not claim that any real legal or regulatory obligation uses this period.
